# Spiele 🎮

Meine selbst gebauten Spiele:

| Spiel | Engine | Beschreibung |
|---|---|---|
| [**Monsterwelt**](monsterwelt/) | Roblox (Luau) | Spielt sich wie Pokémon: 18 eigene 3D-Monster fangen, rundenbasiert kämpfen, entwickeln — mit Stadt, Monster-Center, Beeren-Farm, Shop und Trainern. Fertige `.rbxlx` zum Öffnen in Roblox Studio. |
| [**Brain Words**](brain-words/) | Roblox (Luau) | Pokémon-artiges Spiel: verrückte Wörter fangen, kämpfen, leveln und entwickeln. Fertige `.rbxlx`-Datei zum direkten Öffnen in Roblox Studio. |
| [**VoxelCraft**](voxelcraft/) | Godot 4.3 (GDScript) | Minecraft-inspiriertes Voxel-Sandbox-Spiel mit prozeduraler Welt, Crafting, Farming und Mobs. |
